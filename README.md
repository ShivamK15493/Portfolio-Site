<h1>🌐 Personal Portfolio</h1>
This is a personal portfolio website built using HTML and CSS to showcase my profile, skills, projects, and contact information. The website is designed to provide a clean and responsive user interface where visitors can learn more about me and explore my work.

<h2>📌 Features</h2>
<li>Responsive navigation bar with smooth section navigation</li>
<li>Introduction section with profile image and social media links</li>
<li>About section displaying profile information and skill levels</li>
<li>Skills progress bars showing proficiency in different technologies</li>
<li>Contact section with phone, email, address, and GitHub</li>
<li>WhatsApp quick contact button</li>
<li>Clean and organized layout using CSS Flexbox</li>

<h2>🛠️ Technologies Used</h2>
<li>HTML5 – Structure of the webpage</li>
<li>CSS3 – Styling and layout</li>
<li>Flexbox – Responsive layout management</li>
